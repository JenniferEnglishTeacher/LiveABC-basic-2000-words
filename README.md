## Optional sentence pronunciation practice

Units 1–3 include Part 4 with the browser's speech-to-text recognition. Students can listen to each original vocabulary sentence, read it aloud, see what the browser heard, and receive a word-similarity score. A score of 80% is marked as passing, but pronunciation practice is optional and never blocks the next word.

Current Chrome or Edge is recommended. The page asks for microphone permission before recognition. Audio is handled by the browser's speech-recognition service; this website does not upload recordings to its own server.

Validation: 30 source sentences and JavaScript syntax checked; browser checks cover optional navigation, pass/fail feedback, no website audio upload, and mobile layout. This is a speech-to-text similarity check, not phoneme-level pronunciation assessment.
